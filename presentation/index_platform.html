03 / the rule for using AI

AI helps with tasks.
People make the decisions.

01
AI can speed up tasks

Context gathering, alternatives, starter code, test ideas, and review prompts.

02
People decide

Intent, boundaries, trade-offs, acceptance criteria, and output rules.

03
Checks and guardrails

Tests and review show what changed. Automatic quality gates keep AI-generated code within the team's standards.

04
Use resources responsibly

Choose the model and context for the task. Keep context small and do not use the most expensive model for every request.

AI can propose a change. The team decides whether it stays.

Here is the rule for this session: AI helps with the work; people own the problem, the decisions, and the checks.

An agent is useful for gathering context, suggesting options, writing a first test, or finding a suspicious edge case. But the agent does not know which interpretation the business actually wants unless we make that visible. It also cannot decide whether an internal fixture field is safe to expose to an event coordinator.

So we will treat every generated result as a proposal. We keep a change when the behavior is written down, the implementation has tests, another person or tool has reviewed it, and automatic quality gates can run again.

There is also a cost to each request. Choose a model for the task, keep the context clean and small, and avoid spending the most expensive model and the most tokens when a smaller request will do.
